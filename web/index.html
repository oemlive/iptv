📖 怎么用？

1. 直接看结果

打开页面即可查看仓库自动生成的直播源。无需 PAT。

2. 添加自己的源

把 M3U/TXT 地址粘贴到“直播源地址”，点击“加载直播源”。成功后会在本机预览并可筛选、导出。

3. 控制 GitHub Actions

点击“高级控制”，填写仓库信息。PAT 是 GitHub 的远程操作凭证，只有“立即运行 / 取消 / 重跑 / 保存调度”才需要。

4. 加载失败怎么办？

很多直播源服务器禁止浏览器跨域（CORS）。这种情况下不是地址一定失效，而是浏览器不允许网页直接读取；可把地址交给仓库爬虫验证，或使用 GitHub Raw 等允许跨域的地址。

⚙ GitHub 高级控制

公开查看不需要 PAT；仅执行远程写操作时才需要。

PAT 仅保存在当前页面内存，刷新后清除。不要写入仓库、URL、localStorage 或代码。建议 Fine-grained PAT，仅授予目标仓库必要权限。
